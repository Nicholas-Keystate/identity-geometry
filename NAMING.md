# The naming ledger — confessed gestation

**Nothing in this repository is finally named.** The objects are
settled; their names are provisional working labels, held open
deliberately: names bind when they have survived dialogue, and
several of these have survived one sitting or none. This file is
the register of what is still ripening, so that no consumer
mistakes a working label for a coinage.

Renaming any of these is an ordinary succession in this ledger:
the old label is retired with a pointer, consumers re-pin at their
own pace, and nothing pretends the earlier revision did not exist.
